# Influencer WorkMate

เว็บไซต์ช่วยอินฟลูเอ็นเซอร์จัดการงานและกำหนดส่ง สร้างด้วย Python + Streamlit

## วิธีเปิดใช้งานบนคอมพิวเตอร์

1. ติดตั้ง Python 3.10 ขึ้นไป
2. แตกไฟล์ ZIP
3. เปิด Terminal / Command Prompt ในโฟลเดอร์ `Influencer_WorkMate_Project`
4. ติดตั้งไลบรารี:

```bash
pip install -r requirements.txt
```

5. เปิดเว็บไซต์:

```bash
streamlit run app.py
```

6. เปิด URL ที่แสดงใน Terminal โดยปกติคือ `http://localhost:8501`

## ความสามารถ
- เพิ่มงานของแบรนด์ พร้อมชื่องาน แพลตฟอร์ม วันส่ง ค่าจ้าง สถานะ และหมายเหตุ
- แสดงงานใกล้ส่ง งานครบกำหนดวันนี้ และงานเลยกำหนด
- กรองรายการตามสถานะและกำหนดส่ง
- เปลี่ยนสถานะงานและลบงาน
- แสดงจำนวนงานและมูลค่าค่าจ้างรวม
- เรียงงานที่ยังไม่เสร็จตามวันครบกำหนด

## เนื้อหา Python
- ตัวแปรและชนิดข้อมูล
- `if`, `elif`, `else`
- `for` loop
- functions
- `list` และ `dictionary`
- การคำนวณวันที่ด้วย `datetime.date` และ `timedelta`
- Streamlit widgets และ `session_state`

## ข้อจำกัด
ข้อมูลในตัวอย่างเก็บใน `st.session_state` ไม่ใช่ฐานข้อมูลถาวร และไม่มีการส่ง push notification เมื่อปิดเว็บไซต์ หากต้องการพัฒนาต่อสามารถเพิ่ม SQLite และระบบแจ้งเตือนภายนอกได้
